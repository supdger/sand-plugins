## Context

权威提供方为 `sand_plugins/sand-package`，仓库 HEAD 为 `61fd9b1d2692e27035cc33eb5d9c44ee17bdf561`，工作区已有大量未提交变更。基线以当前源码相关文件 SHA-256 固定，隔离候选和日志置于 `/tmp`，独立审查通过后只应用本任务精确差异。

调用方场景包括 SandIAM 与 SandWorkflow 的 ZIP 支持声明；现场宿主 SandAdmin 为 `0.1.2`。目录中的 composer 包名称为 `supdger/sand-package`，版本由外部 tag/Composer 锁定，而非重新解释 ZIP 的 `support=6.x`。本候选未选择公开发布版本，也不覆盖用户宿主安装副本。

现有公开匹配方式由独立 Astra 实际执行前端原函数验证：宿主 `0.1.2` 对 `6.x`、`0.1.x`、`>=0.1.0` 均拒绝，`0.x` 接受。`0.x` 同时接受低于所需最低版本的 `0.0.x` 且拒绝未来 `1.x`，不能表达最低版本契约；把宿主版本伪装成 `6.x` 会改变真实版本身份。提供方自身拥有包兼容判断，因此通用范围匹配是其职责，没有迁入调用方身份、权限或业务数据。

跨插件准入由未参与实现的独立 Astra 审查，主协调 Agent 已转交通过结论：允许最小通用范围能力，保留历史语义，不特判业务 app，不删已有升级预检。此结论授权范围内复用，候选实现仍需独立验收。源码 AGENTS 要求："Astra 负责前端设计与实现，并由不同上下文的 Astra 独立验收"；前端候选据此由 Astra 实现，PHP 与共享数据集由 Sol 实现。

## Goals / Non-Goals

**Goals:** 兼容结果前后端一致，最低/最高边界包含稳定版本；普通安装及升级拒绝均在依赖与 SQL 副作用前；非法声明或缺失宿主版本关闭放行。

**Non-Goals:** 本变更不实现完整 npm/Composer semver 表达式，不改变 `6.x` 身份，不修改 Legacy 其他恢复路径，不执行宿主安装、数据库脚本、同步、重启、提交、推送或发布。

## Decisions

1. 分支支持 `N.x`、`N.M.x`、`>=X.Y.Z`、`>=X.Y.Z <=A.B.C`，用 `|` 并集；任一分支非法则整表达式拒绝。上下界只接受无前导零稳定三段版本；分支边界允许空格/tab，范围内允许空格/tab，不允许 CR/LF。没有上界时未来主版本达到最低值即可接受，不推造上限。
2. 宿主继续接受严格 SemVer prerelease/build，拒绝数字 prerelease 前导零与 v 前缀。build 忽略，宿主核心等于最低稳定版本但带 prerelease 时拒绝；核心高于最低版的 prerelease 可接受；主/次版本通配符保持原 prerelease 可匹配语义。
3. composer 当前没有可复用 semver 库。PHP `version_compare` 实测超大合法数字三段版本返回错误等值（`999999999999999999999999999999.0.0` 对 `888888888888888888888888888888.0.0` 为 0）；使用十进制字符串长度及字典序逐段比较，前端采用相同语义，不新增依赖，也不扩建 prerelease 全序比较。
4. PHP 一个无状态 matcher；Legacy 仅在已有 `assertHostSupportsUpgrade` 中调用。普通 `install()` 先校验真实配置 `plugin.sandadmin.app.version` 和候选 `support`，再处理依赖；拿锁后再次校验候选，避免绕过管理页面。所有候选注册、依赖安装、数据库脚本、载荷部署仍归原安装器。
5. 共享 JSON 边界样例供两端真实函数直接调用；后端实际 `install(false)` 对中立包的拒绝路径以依赖边界/SQL记录器验证，接受对照须触达依赖边界，从而避免只检查源代码文本。

## Risks / Trade-offs

- 缺失或旧错误 support 的包会被后端正式拒绝 → 保留候选现场并给出业务错误，元数据应由插件权威来源改正。
- 前后端源码发布必须同版本消费 → 提供共享数据集和实际入口检查；源码候选通过不等于用户旧 Composer 安装副本已经获得能力。
- 未完成真实宿主安装和浏览器验收 → 本次仅记录候选行为验证；用户原话“落地，并且解决问题”覆盖源码实现及必要本地回归，不扩展到安装、服务或 DB 操作。

## Migration Plan

独立验收候选后核对基线哈希，只应用精确差异到权威源码并复测。回滚只撤回本任务新增 helper、入口差异及前端引用，不删除或覆盖已有 dirty 修改。公开修复版本及消费宿主更新需另行授权；不得整体打包 dirty SandPackage 覆盖用户 `0.1.5`。

## Purpose

保障管理员在标准插件安装触发短暂服务重载时可以继续管理端导航，不因初始化请求的瞬时断连永久停留在错误页，同时保持权限拒绝、业务错误、会话隔离与持续故障的明确终止行为。

## ADDED Requirements

### Requirement: 初始化暂态故障有限恢复

管理端 SHALL 仅针对核心用户、字典和菜单初始化的幂等 GET 自动恢复明确的短暂网络断连或空 HTTP 500/502/503，整个恢复窗口最多 15 秒，每个请求最多 6 次尝试；成功后继续原有效目标导航。系统 MUST 不自动重发安装或其他写请求。

#### Scenario: Windows 安装后重载恢复

- **WHEN** 管理员完成插件安装后，初始化 GET 因服务重载短暂失败且在预算内恢复
- **THEN** 管理端继续现有加载状态，恢复后正常显示目标页面和菜单，过程中不跳 `/500`、不反复弹出内部错误

#### Scenario: 持续不可用

- **WHEN** 初始化服务持续不可用，尝试次数或时间预算耗尽
- **THEN** 管理端停止自动重试，结束加载并沿用失败页面及最终错误反馈

### Requirement: 保留权限与真实错误边界

系统 MUST 不重试身份失效、权限拒绝、明确业务错误、非空服务端错误响应、无效菜单、取消和请求超时；对应错误仍按既有登录、403 或 500 处理，不伪报安装成功。

#### Scenario: 认证与权限拒绝

- **WHEN** 初始化返回 401 或 403
- **THEN** 不等待恢复窗口，分别沿用登录失效或权限拒绝流程

#### Scenario: 真正的业务或结构错误

- **WHEN** 初始化返回结构化业务失败、非空错误响应或无效菜单数据
- **THEN** 不自动重试该失败，保留原失败处理

### Requirement: 恢复过程保持会话隔离

系统 SHALL 在同一登录会话内共享初始化恢复过程，只在所有有效数据齐备后一次性注册路由；会话失效后旧过程 MUST 不再启动重试或写入新会话状态。

#### Scenario: 并发导航

- **WHEN** 恢复期间发生多个导航
- **THEN** 共用同次初始化，成功后路由不重复注册

#### Scenario: 等待中退出或重新登录

- **WHEN** 恢复等待期间用户退出或进入新会话
- **THEN** 旧初始化结果和后续重试不能覆盖新会话数据或导航

### Requirement: 遮罩所有权与完整收尾

管理端 SHALL 以实际加载实例和导航 owner 管理遮罩，在导航完成、失败、取消、会话重置及加载模块替换时释放对应遮罩。后置守卫 MUST 不依赖另一模块局部 pending 布尔，旧导航回调 MUST 不关闭新导航遮罩。

#### Scenario: 守卫模块重新求值后完成导航

- **WHEN** 初始化开启遮罩后前后守卫来自不同模块实例，导航恢复并完成
- **THEN** 目标页可操作且遮罩结束，无需手动刷新

#### Scenario: 旧导航晚完成

- **WHEN** 旧导航的失败、取消或延后回调到达时新导航已取得遮罩
- **THEN** 保留新导航遮罩，由新导航完成时关闭

### Requirement: 仓库只读请求有限恢复

Package SHALL 仅对已安装列表与 catalog GET 的明确网络失败或空 HTTP 500/502/503 进行最多四次重试，并在 15 秒内发起重试，保留 catalog 单请求 65 秒超时。系统 MUST 不重试写请求、401/403、取消、超时及非空业务失败。

#### Scenario: 安装后仓库暂态失败

- **WHEN** 安装重载导致列表 GET 暂态失败后恢复
- **THEN** 原页面自动显示已安装及仓库列表，持续失败则结束等待并保留真实错误

#### Scenario: 离开页面或会话变更

- **WHEN** 请求等待时发生切 tab、deactivate/unmount 或会话变更
- **THEN** 旧读取与重试失效，旧结果、错误和收尾不覆盖新状态

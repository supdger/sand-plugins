## Purpose
让管理员通过插件仓库发现远端目录中适配当前 SandAdmin 宿主的最高插件版本，清晰对照已安装版本后自行决定安装或升级，并在读取失败时避免将旧目录误认为最新结果。

## ADDED Requirements
### Requirement: 最新兼容版本推荐
系统 SHALL 按插件版本顺序推荐符合当前宿主范围的最高版本，与目录数组顺序及本地恢复状态无关，并保留所有版本详情。
#### Scenario: 清单乱序且最高版本不兼容
- **WHEN** 清单含旧版本、较新兼容版本与最高但不兼容版本
- **THEN** 卡片推荐较新兼容版本，详情说明最高版本的宿主要求
#### Scenario: 没有兼容版本
- **WHEN** 所有远端版本均不满足宿主要求
- **THEN** 明示没有兼容版本且不提供卡片安装动作
### Requirement: 返回仓库重新读取
系统 SHALL 在进入仓库和缓存页面重新激活时重新获取远端目录，读取中或失败时不暴露过期安装动作。
#### Scenario: 返回及请求乱序
- **WHEN** 返回仓库发起新请求而旧请求随后完成
- **THEN** 仅最新请求更新页面；失败可重试且旧目录不得冒充最新
### Requirement: 用户决定升级
系统 SHALL 展示安装版本、推荐目标与预发布信息，仅用户明确操作并通过原有确认后执行安装升级。
#### Scenario: 已安装较旧版本
- **WHEN** 存在更高兼容版本
- **THEN** 显示目标版本升级按钮且不自动安装

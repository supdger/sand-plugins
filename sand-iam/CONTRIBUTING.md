# Contributing to SandIAM

感谢你改进 SandIAM。提交改动表示你有权贡献相关代码和文档，并同意贡献内容按项目 `LICENSE` 发布。

## 开始之前

1. 先阅读根 `README.md`，确认变更属于通用 IAM 能力而不是某个行业的业务规则。
2. 不要提交密钥、令牌、真实账号、个人数据、数据库备份、本机路径或内部任务材料。
3. 数据库仅支持 PostgreSQL；插件表使用 `sand_iam_*`，不得创建 `sa_*` 业务表。
4. 不要修改已经发布的迁移；修复结构或数据必须追加新迁移并提供升级和重复执行验证。
5. 保留公开接口、错误码和组织/应用/环境隔离语义。不兼容变更必须先说明版本与迁移方案。

## 提交内容

- 用一个可复现的问题、用例或需求说明为什么要改。
- 采用最小且完整的业务变更，补充正向、拒绝、撤销/恢复和审计测试。
- 更新受影响的 PHP、SDK、管理端、门户、SQL 和公开文档；不要只改一侧契约。
- 运行相关静态检查、单元/契约测试和包完整性检查，并记录实际命令和结果。
- 涉及协议互操作时使用标准客户端或真实受控对端；mock 只能作为开发回归，不能替代互操作证据。

## 本地检查

不连接数据库的基础检查：

```sh
php tools/check-package-integrity.php
php tools/check-release-payload.php
php tools/generate-sbom.php --check
```

PHP 文件应通过 `php -l`，TypeScript 和 Dart SDK 应使用各自锁定依赖完成类型检查与测试。
数据库、宿主、浏览器和外部协议验证必须使用隔离环境，并先取得该环境负责人的授权。

## 评审要求

评审应分别说明已检查、已修改、已验证和未验证的范围。源码存在、构建通过或候选包生成，
都不能替代真实安装、升级、浏览器、协议、业务副作用和清理验证。

安全缺陷不要提交公开 issue 或普通 pull request，请按 `SECURITY.md` 私下报告。

## Consumer or build dependencies not copied into this package

`node_preamble` 2.0.2 contains BSD-3-Clause and MIT material, and `yaml` 3.1.3
uses MIT. The merged portal and TypeScript SDK
locks contain 28 npm packages: TypeScript 5.9.3 uses Apache-2.0; esbuild 0.25.10 and
its 26 platform packages use MIT. These are build, SDK-consumer, or test dependencies
and their package trees are not copied into the SandIAM release payload. Exact
coordinates, SPDX identifiers, package hashes where available, dependency scopes,
and license evidence URLs are recorded in `SBOM.cdx.json`.

MIT-licensed and are not redistributed by SandIAM as separate dependencies.
